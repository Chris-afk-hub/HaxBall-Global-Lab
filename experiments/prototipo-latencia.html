PROTOTIPO 01 · SIMULACIÓN LOCAL

Laboratorio de latencia

Primera prueba visual para entender qué puede y qué no puede hacer la predicción local. No se conecta a HaxBall ni cambia tu ping real.

Configurá el escenario

Amarillo = posición estimada localmente. Blanco = estado remoto simulado con demora. Mové el control para comparar.

Lectura de esta prueba

Latencia simulada205 ms
Demora visual simulada103 ms
Predicción localActiva

La predicción mueve la representación local de inmediato, mientras que el estado remoto llega más tarde. Esto es una demostración conceptual, no una medición de red.

Qué falta para un prototipo real

  1. Validar cómo se puede leer y simular el estado de una partida con node-haxball.
  2. Crear una sala de prueba separada y medir ping real desde Argentina.
  3. Probar predicción/reconciliación solo si el cliente puede reproducir la misma física que el host.
  4. Comparar la sensación de movimiento sin esconder errores de colisión, goles o posición.

Importante: la página no reduce el ping de HaxBall. Sirve para explorar el concepto antes de intentar una integración real, que requiere un host Node.js y pruebas con jugadores.
